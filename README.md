# ☕ Skyy Store - Kopi Premium untuk Anak Muda

Skyy Store adalah proyek website *coffee shop* modern yang dibangun menggunakan **HTML5, CSS3, dan JavaScript**. Website ini tidak hanya berfungsi sebagai katalog, tetapi juga memiliki fitur interaktif untuk pengalaman belanja pengguna yang lebih nyata.

## ✨ Fitur Utama
* **Hero Section:** Tampilan utama elegan dengan ajakan untuk melihat koleksi produk.
* **Katalog Produk:** Daftar menu kopi dan minuman (Macchiato, Thai Tea, dll) dengan desain kartu yang rapi.
* **🛒 Fitur Add to Cart:** Pengguna bisa menekan tombol "Beli" dan produk akan otomatis masuk ke dalam daftar keranjang belanja (Manage by JavaScript).
* **Shopping Cart Tracker:** Melacak jumlah dan detail barang yang ingin dibeli oleh pelanggan.
* **Modern & Responsive UI:** Menggunakan tema warna gelap yang memberikan kesan premium dan nyaman di mata.

## 🛠️ Teknologi yang Digunakan
* **HTML5:** Menyusun kerangka dasar, konten, dan struktur keranjang belanja.
* **CSS3:** Menangani styling, tata letak, serta efek visual neon dan bayangan pada kartu produk.
* **JavaScript:** Otak di balik fitur **Add to Cart**, menangani penyimpanan data produk sementara, serta memperbarui tampilan keranjang secara *real-time*.

## 🚀 Cara Menjalankan
1. Download atau Clone repositori ini.
2. Buka folder proyek di komputermu.
3. Klik kanan pada file `index.html` dan pilih **Open with Browser**.
4. Coba tekan tombol **Beli** dan lihat bagaimana produk masuk ke keranjang!
